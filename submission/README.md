# SUSCOM submission notes (fetched 2026-09-01)

- Target: Sustainable Computing: Informatics and Systems (Elsevier, ISSN 2210-5379), hybrid; subscription route has no APC.
- Guide for Authors: https://www.sciencedirect.com/journal/sustainable-computing-informatics-and-systems/publish/guide-for-authors
- First submission is "Your Paper Your Way": no strict format; needs Abstract, Keywords, Introduction, Methods, Results, Conclusions, captioned artwork/tables. A plain Word or PDF file is acceptable; no journal-specific Word template exists.
- LaTeX (optional, for revision/camera-ready): elsarticle class, in elsarticle/ here (from https://mirrors.ctan.org/macros/latex/contrib/elsarticle.zip, v3.5). Use elsarticle-template-num.tex; references are numbered [1] style (elsarticle-num.bst).
- Declarations: interests statement and CRediT author contributions required; graphical abstract optional.
- Submission system: Editorial Manager, https://www.editorialmanager.com/suscom/default.aspx
- Unverified (ScienceDirect blocks bots; check in browser): anonymization mode, Highlights required vs optional, word limits, first-decision time.
